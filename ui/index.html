What this tool does

The Multi-Timeframe Stock Screener automatically scans your watchlist for trading setups by combining candlestick pattern recognition with technical indicator signals across two timeframes — Daily (trend direction) and 1-hour (entry trigger). Results are scored by confluence and ranked into two actionable lists.

How to use it

  • Run Fresh Scan — click the button in the header to fetch live data and analyse all tickers in your watchlist. A scan typically takes 3–10 seconds.
  • Read the results — the LONG table lists bullish setups ranked by score. The SHORT table lists bearish setups. Higher absolute score = stronger confluence.
  • Inspect a signal — click any result row to open the candlestick chart for that ticker. Toggle Daily / 1h to verify the pattern visually.
  • Manage your watchlist — click ⚙ Watchlist to add or remove tickers. Up to 200 tickers supported.

Understanding the score

Each confirmed signal contributes one point. Bullish signals add +1; bearish signals add −1. Both Daily and 1h are evaluated independently — maximum ±8 per ticker.

Signal date labels

Each signal shows the candle date — e.g. Hammer (daily, Sep 25). A ⚠ stale flag means the candle is older than expected. Always confirm you are acting on a current signal.

Chart panel tips

  • Click any result row to open its candlestick chart on the timeframe of the first detected signal.
  • Toggle Daily and 1h — daily shows the trend, 1h shows the entry timing.
  • High-volume candles on a signal increase confidence. Volume is shown as a histogram below the candles.
  • Close the chart with ✕ Close, clicking the backdrop, or pressing Escape.

Tie-breaking sort order

Equal scores are broken by: 1h volume (higher first) → absolute 1h % change → alphabetical by ticker.

Important limitations

  • This tool is for personal research only — not financial advice.
  • Data is fetched on demand from Yahoo Finance and reflects the most recent complete candle, not real-time tick prices.
  • Always verify visually using the chart panel before acting on any signal.
  • An internet connection is required for data fetching and chart rendering.

What is this tool?

The Multi-Timeframe Stock Screener is a Python desktop application that automates scanning a watchlist for high-probability trading setups. Instead of reviewing charts one by one, run a single scan and see the strongest confluent signals ranked and ready to verify.

How it works

  • Data fetch — live OHLCV data is downloaded from Yahoo Finance concurrently for all watchlist tickers: 90 days of daily candles and 30 days of 1-hour candles.
  • Pattern detection — eight candlestick patterns are evaluated on the most recent complete candle using price-action math: Hammer, Shooting Star, Bullish/Bearish Engulfing, Morning Star, Evening Star, and context-aware Bullish/Bearish Doji.
  • Indicator detection — MACD (12, 26, 9) for momentum crossovers, Bollinger Bands (20-period, 2σ) for volatility extremes, and RSI (14-period) for overbought/oversold conditions.
  • Confluence scoring — each fired signal contributes ±1 to a net score. Tickers are split into LONG and SHORT lists, sorted by signal strength.

Technology

  • Runtime: Python 3.10+ desktop application
  • Window: pywebview (native OS window, no browser required)
  • Backend: Flask on localhost:5000
  • Data: yfinance (Yahoo Finance OHLCV)
  • Indicators: ta library (MACD, Bollinger Bands, RSI)
  • Charts: lightweight-charts by TradingView (CDN)
  • Frontend: Vanilla HTML, CSS, JavaScript — no framework, no build step

Design principles

  • Transparency — every signal shows what triggered it, which timeframe, and the candle date. Nothing is a black box.
  • Speed — tickers are fetched concurrently (up to 10 parallel requests).
  • Simplicity — the scoring model is additive and equal-weighted. Confluence builds confidence naturally.
  • Verification-first — the chart panel is a first-class feature so you can validate every signal before acting on it.
